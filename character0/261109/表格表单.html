第6章 表格

表格的标记、属性、嵌套与布局

6.1 表格基本标记

表格由3个基本标签构成：

<table>

定义表格容器

<tr>

定义表格行

<td>

定义单元格

<table>
  <tr>
    <td>单元格1</td>
    <td>单元格2</td>
  </tr>
</table>

📌 基本语法中常使用 <th> 定义表头单元格（居中加粗）。

表格实例 · 课程表

课程表
节次 \ 星期 星期一 星期二 星期三 星期四 星期五
第12节 体育 大学英语 高等数学 数据结构实验 Web开发
第34节 大学英语 高等数学 数据结构 数据结构 Web开发实验

表格使用 <caption> 定义标题，使用 <th> 定义表头，使用 <td> 定义数据单元格。

表格标题与表头

<caption> 表格标题

用于对表格内容进行简单说明，必须紧随 <table> 标记之后。

<table>
  <caption>课程表</caption>
  ...
</table>

<th> 表头单元格

定义表格第一行（或列）的标题，文字默认居中、加粗显示。

<tr>
  <th>节次</th>
  <th>星期一</th>
  ...
</tr>

表格常用属性

边框与尺寸

  • border：边框宽度，默认0（无边框）
  • bordercolor：边框颜色
  • width / height：表格宽度/高度
  • cellspacing：单元格间距
  • cellpadding：单元格边距（内容与边框距离）

背景与对齐

  • bgcolor：背景颜色
  • background：背景图像（GIF/JPEG/PNG）
  • align：表格水平对齐（left/center/right）
  • frame：控制外边框显示（void/above/below/hsides/vsides/lhs/rhs/box/border）
  • rules：控制内部边框显示
<table width="600" border="1" bordercolor="#00FF00" bgcolor="#f5f5dc" cellspacing="15" cellpadding="10" align="center">

行属性与单元格合并

<tr> 行属性

  • align：行内容水平对齐（left/center/right）
  • valign：行内容垂直对齐（top/middle/bottom）
<tr align="center" valign="top"> ... </tr>

单元格合并

  • rowspan：跨行合并（纵向）
  • colspan：跨列合并（横向）
<td rowspan="2">合并两行</td>
<td colspan="3">合并三列</td>

合并后需注意减少对应行/列中单元格的数量，保持表格结构正确。

表格嵌套与页面布局

表格嵌套

在一个表格的单元格内再插入表格，可实现复杂布局。

<table>
  <tr>
    <td>
      <table>
        <tr><td>嵌套表格</td></tr>
      </table>
    </td>
  </tr>
</table>

⚠️ 嵌套层次越多，页面加载速度越慢。

表格布局实例

<table width="650" align="center" border="1">
  <tr>
    <td width="150" height="80">网站标志</td>
    <td colspan="2">广告条</td>
  </tr>
  <tr>
    <td>导航条</td>
    <td>内容一</td>
    <td>内容二</td>
  </tr>
  <tr>
    <td colspan="3" align="center">版权信息</td>
  </tr>
</table>

利用表格进行页面排版，效果稳定，但现代网页更推荐 DIV+CSS。

第7章 表单

表单标记、输入控件与交互元素

7.1 表单的概念

表单用于收集用户信息并提交给服务器，是网站与浏览者沟通的桥梁。

两个组成部分

  • 描述表单的 HTML 源代码
  • 处理信息的服务器端应用程序（如 ASP.NET、JSP）

<form> 标记

成对出现，首尾标记之间的部分即为一个表单。

<form name="..." action="..." method="...">
  ...
</form>
  • name：表单名称，便于脚本控制
  • action：指定处理表单信息的服务器端应用程序
  • method：提交方式，get（默认）或 post

7.2 输入控件 <input>

<input> 是单标记，必须嵌套在表单中使用。常用属性：

核心属性

  • type：输入类型（必选）
  • name：变量名（必选）
  • value：初始值 / 提交值
  • size：显示宽度
  • maxlength：最大输入字符数
  • checked：默认选中（单选/复选）

常用 type 类型

📝 text🔒 password ✅ checkbox🔘 radio 📤 submit🔄 reset 🖼️ image📎 file 👻 hidden🔘 button

7.2.1 ~ 7.2.3 文本、密码与按钮

文本框 text

<input type="text" name="yourname" size="15" maxlength="20" value="请输入姓名">

size 为显示宽度，maxlength 为最大字符数。

密码框 password

<input type="password" name="yourpw" size="15">

输入内容以圆点/星号代替，保护密码安全。

提交按钮 submit / 重置按钮 reset

<input type="submit" value="提交">
<input type="reset" value="重置">

表单中必须有提交按钮才能向服务器传送信息；重置按钮清除所有输入并恢复初始状态。

7.2.4 ~ 7.2.8 选择与文件类控件

复选框 checkbox

<input type="checkbox" name="basketball" value="basketball" checked> 篮球

可多选；name 各不同，value 必填。

单选框 radio

<input type="radio" name="mail" value="10" checked> 10封

同组 name 必须相同，value 各不同。

图像按钮 image

<input type="image" src="confirm.gif" value="提交">

src 必需，点击即提交表单。

文件选择 file / 隐藏 hidden

<input type="file" name="uploadfile">
<input type="hidden" name="id" value="1001">

file 用于上传文件；hidden 在页面中不可见，用于传递隐藏数据。

7.3 ~ 7.4 文本域与下拉列表

<textarea> 多行文本域

<textarea name="suggest" cols="50" rows="3" wrap="soft"></textarea>
  • rows：行数（高度）
  • cols：列数（宽度）
  • wrap：自动换行方式

<select> / <option> 下拉列表

<select name="sports" size="1" multiple>
  <option value="football" selected>足球</option>
  <option value="basketball">篮球</option>
</select>
  • size：显示选项数，>1 时显示为列表框
  • multiple：允许多选
  • selected：默认选中

7.5 按钮、标签与分组

<button> 按钮

<button type="submit">提交</button>

内部可放置文本或图像，务必指定 type（button/reset/submit）。

<label> 标签

<label for="userName">用户名：</label>
<input type="text" id="userName">

点击标签文字即可聚焦对应控件，for 与 id 对应。

<fieldset> 与 <legend> 分组

<fieldset>
  <legend>请登录</legend>
  <label for="user">用户名：</label>
  <input type="text" id="user">
</fieldset>

本章总结 · 表格与表单

📊 表格核心

  • <table>、<tr>、<td>、<th> 构成基本表格
  • <caption> 定义标题
  • 属性：border、width/height、bgcolor、background、cellspacing、cellpadding、align
  • 行属性：align、valign
  • 合并：rowspan（跨行）、colspan（跨列）
  • 表格嵌套可实现复杂布局

📝 表单核心

  • <form> 定义表单，method 为 get/post
  • <input> 根据 type 呈现不同控件：text、password、checkbox、radio、submit、reset、file、hidden、image 等
  • <textarea> 多行文本
  • <select> + <option> 下拉列表
  • <label> 提升可用性；<fieldset> 分组

掌握表格与表单，即可构建结构清晰、交互友好的网页！
