5.1 超链接简介

  • 链接是什么？链接是一种用于在不同网页之间导航的元素。
  • 链接的作用？链接通常用于将一个网页与另一个网页或资源（如文档、图像、音频文件等）相关联。允许用户在浏览网页时单击文本或图像来跳转到其他位置，从而实现网页之间的互联。

超链接（hyperlink）是一个网站的精髓，超链接在本质上属于一个网页的一部分，它是一种允许一个网页同其他网页或站点之间进行链接的元素。各个网页链接在一起后，才能真正构成一个网站。

超文本具有的链接能力，层层链接相关文件，这种具有超级链接能力的特性，即称为超链接。

超链接除了可链接文本外，也可链接各种媒体，如声音、图像和动画等，通过它们可以将网站建设成一个丰富多彩的多媒体世界。

5.2 创建超链接

超链接的标记：建立超链接的标记是 a (anchor, 锚)，以 <a> 开始，以 </a> 结束，锚可以指向网络上的任何资源：一张 HTML 页面，一幅图像，一个声音或视频文件等。

基本语法：

<a href="url" title="指向链接显示的文字" target="窗口名称">链接内容</a>
  • href：定义了这个链接所指的目标地址，也就是路径。理解一个文件到要链接的那个文件之间的路径关系是创建链接的根本。
  • Target：有 4 个保留的目标名称用作特殊的文档重定向操作。
    • _blank：在新窗口中打开被链接文档。
    • _self：默认。在相同的框架中打开被链接文档。
    • _parent：在父框架集中打开被链接文档。
    • _top：在整个窗口中打开被链接文档。
    • framename：在指定的框架中打开被链接文档。

5.2.1 外部链接

所谓外部链接，指的是跳转到当前网站外部，与其它网站中页面或其它元素之间的链接关系。这种链接的 URL 地址一般要用绝对路径，要有完整的 URL 地址。

<!-- 程序 5-1 -->
<html>
<head><title>创建链接</title></head>
<body>
  <a href="http://www.sina.com.cn">新浪</a><br>
  <a href="http://www.baidu.com">百度</a><br>
  <a href="http://www.hdu.edu.cn">杭州电子科技大学信息工程学院</a>
</body>
</html>

5.2.2 内部链接

所谓内部链接，指的是在同一个网站内部，不同的 HTML 页面之间的链接关系，在建立网站内部链接的时候，要明确哪个是主链接文件（即当前页），哪个是被链接文件。

5.3.1 图片链接

可以为一个图片指定链接。

基本语法：

<a href="url" target="目标窗口的打开方式"><img src="图片地址"></a>

示例代码：

<!-- 程序 5-2 -->
<html>
<head><title>建立图片链接</title></head>
<body>
  <center>
    <h2>图片链接</h2>
    <hr>
    <a href="http://www.baidu.com" target="_blank">
      <img src="images/baidu_logo.gif" />
    </a>
  </center>
</body>
</html>

5.3.2 书签链接

在浏览页面时，如果页面篇幅很长，要不断的拖动滚动条，给浏览带来不便。要是浏览者既可以从头阅读到尾，又可以很快寻找到自己感兴趣的特定内容进行部分阅读，这个时候就可以通过书签链接来实现。当浏览者单击页面上的某一“标签”，就能自动跳到网页相应的位置进行阅读，给浏览者带来方便。

基本语法：

  • 在同一页面内要使用书签链接的格式：
    <a href="#书签名称" target="窗口名称">链接标题</a>
  • 在不同页面之间要使用书签链接的格式（在不同页面中链接的前提是需要指定好链接的页面地址和链接的书签名称）：
    <a href="URL地址#书签名称" target="窗口名称">链接标题</a>
  • 以上两种书签链接形式，链接到的目标为：
    <a name="书签名称">链接内容</a>

书签链接 · 示例

页面顶部导航：

<a href="#T1">数据结构</a>
<a href="#T2">计算机组成原理</a>
<a href="#T3">计算机网络</a>
<a href="#T4">人工智能</a>

页面目标位置：

<a name="T1">数据结构</a>
<p>《数据结构》是计算机...</p>
<a href="#">返回页首</a>

5.3.3 下载文件的链接

如果希望制作下载文件的链接，只需在链接地址处输入文件所在的位置即可。当浏览器用户单击链接后，浏览器会自动判断文件的类型，以做出不同情况的处理。

基本语法：

<a href="url">链接内容</a>

示例代码：

<!-- 程序 5-7 -->
<html>
<head><title>下载文件</title></head>
<body>
  <p>这是一本电子书：
    <a href="ds.rar">数据结构 --C#</a>
  </p>
</body>
</html>

5.4 小实例 · Target 属性详解

HTML 结构

<a href="first.html" target="_self">跳转 1</a>
<a href="second.html" target="_blank">跳转 2</a>
<iframe name="big" src="fourth.html"></iframe>

Target 属性说明

  • _self：默认，在当前窗口/框架中打开。
  • _blank：在新窗口中打开。
  • _top：在当前窗体打开链接，并替换当前的整个窗体（框架页），清除所有包含的框架。
  • _parent：在父窗体中打开链接，在窗口与顶级框架中，等同于 _self。

5.5 使用超链接的技巧与建议

  • 一般规则是，对于自己站点上的网页的链接，使用相对 URL；对于其他站点上的资源链接，使用绝对 URL。
  • 如果指定路径但省略文件名，就会链接到目录下的默认文件（网站可以自己定义默认页面），如果路径也省略，就会链接到网站的默认主页。
  • URL 最好使用小写字母来表示。
  • 不要使用“点击这里”作为显示标签，应该使用文本中已经存在的关键词来表示链接。
  • 可以对链接应用样式进行格式化，甚至使用图像作为标签，来吸引用户的注意力。
  • 可以为页面内的链接规定制表符顺序，这样访问者就可以用键盘在页面上移动。
  • 对于供下载的资源，如果超出了一定的大小，最好事先进行压缩，甚至把一个文件分成几个压缩文件，来保证传输的安全。

第5章 总结

  • 本章介绍了超级链接的基本概念和语法。
  • 重点掌握内部链接（相对路径）和外部链接（绝对路径）的使用。
  • 学会创建图片链接、书签链接和下载文件链接。
  • 理解并熟练使用 <a> 标签的 target 属性控制链接的打开方式。
  • 遵循超链接使用的最佳实践和建议，设计出结构清晰、互联性强的网站。
