4.1 列表简介

  • 在制作网页时，列表经常被用到写提纲和品种说明书。
  • 通过列表标记的使用能使这些内容在网页中条理清晰、层次分明、格式美观地表现出来。
  • 顾名思义就是在网页中将相关资料以条目的形式有序或者无序排列而形成的表。
  • 常用的列表有无序列表、有序列表和定义列表三种。另外，还有不太常用的目录列表和菜单列表。

常见列表示例

📰 新闻列表（无序）

  • 湖人宣布将退役奥尼尔球衣
  • 奥尼尔十大时刻：扣碎篮板太暴力
  • 奥尼尔：受伤那刻像中枪 19年了！我会想念这一切
  • 再美的剧情也要结束 别了奥胖！别了！你的青春
  • 火箭正式宣布签约麦克海尔！

🛒 商品分类（有序/菜单）

  • 图书音像
  • 影视、音乐
  • 手机数码、家电
  • 电脑、游戏、软件、办公
  • 家居、厨具、食品
  • 美容化妆、个护健康
  • 运动、户外和休闲
  • 鞋靴、服饰箱包

4.2 无序列表 (Unordered List)

  • 是一个没有特定顺序的相关条目的集合。
  • 各个列表项之间属并列关系，没有先后顺序之分，它们之间以一个项目符号来标记。
<ul type="">
  <li>项目名称</li>
  <li>项目名称</li>
  <li>项目名称</li>
</ul>

type 取值

  • disc：实心圆点（默认）
  • circle：空心圆点
  • square：实心方块

无序列表 · 示例代码 4-1

<!-- 程序 4-1 -->
<html>
<head><title>无序列表</title></head>
<body>
  <b>班级新闻</b>
  <ul type="disc">
    <li>最新课程表</li>
    <li>关于普通话考试的通知</li>
    <li>钢琴名曲音乐欣赏 -- 献给爱丽丝</li>
    <li>中国奥运屈辱史</li>
    <li>div+css 高级应用学习</li>
  </ul>
</body>
</html>

执行效果：每个列表项前出现实心圆点，内容依次排列。

4.3 有序列表 (Ordered List)

  • 是一个有特定顺序的相关条目的集合。
  • 各个列表项有先后顺序之分，它们之间以编号来标记。
<ol type="">
  <li>项目名称</li>
  <li>项目名称</li>
  <li>项目名称</li>
</ol>

type 取值

  • "1"：阿拉伯数字（默认）
  • "a"：小写英文字母
  • "A"：大写英文字母

其他取值

  • "i"：小写罗马数字
  • "I"：大写罗马数字

有序列表 · 示例代码 4-2

<!-- 程序 4-2 -->
<html>
<head><title>有序列表</title></head>
<body>
  <strong>报名</strong>
  <ol type="A">
    <li>报名时间：3月16—21日，逾期不予受理。</li>
    <li>报名地点：所在院系办公室。</li>
    <li>报名费用：按物价局规定 85 元/人/次（含培训费用），报名时交齐。</li>
    <li>提交资料及注意事项：</li>
  </ol>
</body>
</html>

执行效果：列表项前依次显示 A、B、C、D。

4.3.2 编号起始值

  • 使用有序列表标记的 start 属性，可以改变编号的起始值。
  • start 属性值是一个整数，表示从哪一个数字或字母开始编号。
  • 例如，设置 start="3"，则编号将从“3”、“c”、“C”、“iii”或“III”开始。
<ol type="A" start="3">
  <li>报名时间：3月16—21日，逾期不予受理。</li>
  <li>报名地点：所在院系办公室。</li>
  <li>报名费用：按物价局规定 85 元/人/次（含培训费用），报名时交齐。</li>
  <li>提交资料及注意事项：</li>
</ol>

注意：尽管 type="A"，start 的值仍需取阿拉伯数字“3”，而不能取大写字母“C”。

4.3.3 列表项样式

  • 使用列表项标记 <li> 的 type 属性，可以指定单个列表项的符号或编号。
  • 当 <ol> 的 type 属性与 <li> 的 type 属性冲突时，单个列表项遵循 <li> 的 type 属性。
<ol type="A">
  <li>报名时间：3月16—21日，逾期不予受理。</li>
  <li type="1">报名地点：所在院系办公室。</li>
  <li>报名费用：按物价局规定 85 元/人/次（含培训费用），报名时交齐。</li>
  <li>提交资料及注意事项：</li>
</ol>

效果：第二个列表项样式变为阿拉伯数字“2”，后续列表项恢复遵循 <ol> 的 type 属性。

4.3.4 列表项编号

  • 使用列表项标记 <li> 的 value 属性，可以改变当前列表项的编号大小，并影响其后所有列表项的编号大小。
  • 该属性只适用于有序列表。
<ol type="A">
  <li>报名时间：3月16—21日，逾期不予受理。</li>
  <li value="5">报名地点：所在院系办公室。</li>
  <li>报名费用：按物价局规定 85 元/人/次（含培训费用），报名时交齐。</li>
  <li>提交资料及注意事项：</li>
</ol>

效果：第二个列表项及其后所有列表项从字母“E”开始编号。

4.4 嵌套列表

  • 列表还可以嵌套使用，也就是一个列表中还可以包含有多层子列表。
  • 对于内容层次较多的情况，使用嵌套列表不仅使网页的内容布局更加合理美观，而且使其内容看起来更加清晰、明了。
  • 嵌套的列表可以是无序列表的嵌套，也可以是有序列表的嵌套，还可以是无序列表和有序列表的混合嵌套。
<ol type="1">
  <li><strong>报名</strong></li>
  <ol type="A">
    <li>报名时间：3月16—21日，逾期不予受理。</li>
    <li>报名地点：所在院系办公室。</li>
    <li>报名费用：按物价局规定 85 元/人/次。</li>
    <li>提交资料及注意事项：</li>
    <ol type="a">
      <li>填写《河南省普通话水平测试报名表》一份。</li>
      <li>填写准考证一份。</li>
      <li>提交小一寸彩色证件照3张。</li>
    </ol>
  </ol>
  <li><strong>培训</strong></li>
  <li><strong>测试</strong></li>
</ol>

4.5 定义列表 (Definition List)

  • 插入 <dl> 标记，即可自动生成定义列表。
  • 每一项前既没有项目符号，也没有编号，它是通过缩进的形式使内容层次清晰。
<dl>
  <dt>...</dt>
  <dd>...</dd>
  <dd>...</dd>
  <dt>...</dt>
  <dd>...</dd>
</dl>

<dt> 标记

创建列表中的每个元素标题，内容左对齐。

<dd> 标记

创建列表元素的内容描述，内容相对于 <dt> 向右缩进。

定义列表 · 示例代码 4-7

<dl>
  <dt>报名</dt>
  <dd>报名时间：3月16—21日，逾期不予受理。</dd>
  <dd>报名地点：所在院系办公室。</dd>
  <dd>报名费用：按物价局规定85元/人/次（含培训费用），报名时交齐。</dd>
  <dd>提交资料及注意事项：</dd>
  <dt>培训</dt>
  <dd>培训时间：3月31日（星期六）。</dd>
  <dd>培训地点：河南财经学院4号楼503教室（如有变动，以通知为准）。</dd>
  <dd>注意事项：报考同学请自带《普通话水平测试指导》用书（新版）。</dd>
</dl>

执行效果：“报名”和“培训”左对齐，其下的描述内容向右缩进，层次清晰。

4.6 菜单列表和目录列表

菜单列表 <menu>

  • 通常用于显示一个简单的单列表。
  • 一般不做嵌套。
  • 使用和无序列表类似。

目录列表 <dir>

  • 通常用于显示一个多列的文件列表。
  • 可做嵌套。
  • 使用和无序列表类似。

⚠ 注意：这两种列表均不推荐在现代网页中使用，可视为无序列表的特殊形式。

<menu type="disc">
  <li>项目名称</li>
  <li>项目名称</li>
</menu>

<dir>
  <li>项目名称</li>
  <li>项目名称</li>
</dir>

小实例 · 导航条的制作

利用无序列表和 CSS，制作一个简洁的导航条。

HTML 结构

<div class="container">
  <ul id="nav">
    <li class="home">班级首页</li>
    <li class="activity">班级日志</li>
    <li class="personel">个人风采</li>
  </ul>
</div>

CSS 样式

#nav {
  list-style: none;
  font-size: 22px;
  line-height: 40px;
}
#nav li { margin-top: 5px; }
.home {
  border-top: 4px solid #7BC110;
  background: #be6;
}
.activity {
  border-top: 4px solid #ff9900;
  background: #fc3;
}
.personel {
  border-top: 4px solid #ff66ff;
  background: #fcf;
}

拓展 · 基于 DL 标记的简单表格

利用 DL 标记实现一个简单的两列表格布局。

<style type="text/css">
  dl dt {
    background: #5f9be3;
    color: #fff;
    float: left;
    font-weight: bold;
    width: 150px;
    border: 1px solid #131210;
    padding: 10px 5px;
  }
  dl dd {
    padding: 10px 5px;
    border: 1px solid #131210;
  }
</style>
