第8章 CSS 基础

层叠样式表 · 文字段落样式设置

8.1 CSS 简介

什么是 CSS？

Cascading Style Sheet（层叠样式表），用于控制网页的外观和布局。

  • 样式即格式：文字大小、颜色、图片位置、段落、列表等。
  • 层叠：多个样式冲突时遵循“最近优选原则”。
  • 内容与样式分离：修改 CSS 文件即可改变所有引用页面的样式。

核心优势

  • 统一风格，便于维护
  • 提高页面加载效率
  • 实现丰富视觉表现
/* 示例：所有段落变蓝 */
p { color: blue; font-size: 16px; }

8.1.2 CSS 构造 · 样式规则

每个规则由 选择符（selector） 和 声明（declaration） 组成。

selector {
  属性1: 属性值1;
  属性2: 属性值2;
  ...
}

说明

  • 选择符决定哪些元素受影响
  • 声明在大括号内，由属性值对组成
  • 多个属性值对之间必须用分号隔开

注释

/* 此标记应用在文档中 */
h1 { color:red; background:yellow; }

注释不能嵌套，有助于记忆复杂样式规则。

CSS 继承

许多 CSS 属性不仅影响选择符所定义的元素，还会被其后代元素继承。例如，body 中定义的颜色会应用到段落文本。

<!-- 程序 8-1 -->
<html>
<head><title>CSS 的继承性</title>
<style type="text/css">
  body { color:red; }
</style>
</head>
<body>
  <p>CSS 的继承性</p>
</body>
</html>

段落 p 继承了 body 的文字颜色，显示为红色。

8.2 样式表的定义与使用

四种将 CSS 加入网页的方法：

① 直接定义标记的 style 属性

<p style="font-size:18px; color:#003366">文字</p>

仅影响该标记本身，优先级最高。

② 定义内部样式表

<style type="text/css">
  .p1 { font-size:18px; color:blue; }
</style>

在 HTML 头部定义，供当前页面调用。

③ 嵌入外部样式表

<style type="text/css">
  @import url("style.css");
</style>

@import 必须放在样式规则之前。

④ 链接外部样式表

<link rel="stylesheet" type="text/css" href="style.css">

放在 <head> 中，可同时链接多个，靠后的优先。

8.3 定义选择符

选择符决定了格式化应用于哪些元素。常用类型：

元素选择符

p { font-size:16px; color:red; }

所有 p 元素应用此样式。

类选择符

.p1 { font-size:18px; color:blue; }

通过 class="p1" 引用，可应用于多个元素。

ID 选择符

#header { background:#eee; }

通过 id="header" 引用，页面中唯一。

上下文选择符

div p { color:green; }

仅 div 内部的 p 元素应用样式。

CSS 修饰文字与段落

文字样式

  • font-family：字体
  • font-size：字号
  • color：文字颜色
  • font-weight：加粗
  • text-decoration：下划线/删除线
p { font-size: 16px; color: #333; }

段落样式

  • text-align：对齐方式
  • line-height：行高
  • text-indent：首行缩进
  • margin / padding：间距
p { text-align: center; line-height: 1.8; text-indent: 2em; }

第9章 列表与超链接样式

CSS 列表修饰 · 超链接伪类 · 导航菜单实例

9.1 CSS 修饰列表

列表项标记类型

ul { list-style-type: square; }
ol { list-style-type: upper-roman; }

常用值：disc、circle、square、decimal、upper-alpha 等。

使用图片作为标记

ul { list-style-image: url("star.gif"); }

可自定义列表图标。

9.2 CSS 修饰超链接

超链接有四种状态，使用伪类分别定义样式：

伪类选择符

a:link { color: blue; }        /* 未访问 */
a:visited { color: purple; }    /* 已访问 */
a:hover { color: red; }         /* 鼠标悬停 */
a:active { color: green; }      /* 点击时 */

顺序建议：LVHA（link → visited → hover → active）。

9.3 综合实例 · 导航菜单

通过 CSS 列表与超链接样式，制作一个水平导航菜单。

HTML 结构

<ul class="nav">
  <li><a href="#">首页</a></li>
  <li><a href="#">课程介绍</a></li>
  <li><a href="#">教学团队</a></li>
  <li><a href="#">联系我们</a></li>
</ul>

CSS 样式

.nav {
  list-style: none;
  padding: 0;
  margin: 0;
  background: #1e293b;
  display: flex;
}
.nav li a {
  display: block;
  padding: 12px 24px;
  color: #fff;
  text-decoration: none;
  transition: background 0.3s;
}
.nav li a:hover {
  background: #6366f1;
  color: #fff;
}
