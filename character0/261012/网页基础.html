第1章 网页设计简介

1.1 万维网概述

  • WWW (World Wide Web) 是基于超文本方式的信息检索服务工具。
  • WWW 系统在教育、科技、商业、媒体等多方面起重要作用。
  • WWW 是 Internet 上最受欢迎的应用之一，极大推动了 Internet 的推广。
  • 成功秘诀：HTML 超文本开发语言、URL 统一定位格式、HTTP 超文本传送协议。

1.2 HTML 语言

  • HTML = Hypertext Markup Language，超文本标记语言，构成 Web 页面的主要工具。
  • HTML 文档由很多标记组成，可说明文字、图形、动画、声音、表格、链接等。
  • 独立于操作系统平台（UNIX、WINDOWS 等），只需 WWW 浏览器即可访问。
  • 网页是浏览器对 HTML 文件进行解释的结果。

1.3 网页制作开发工具

编辑工具

  • 记事本 (Notepad)：Windows 自带，可编写 HTML 代码。
  • EditPlus：支持颜色标记、HTML 标记，支持多种语言。
  • Dreamweaver：专业 HTML 编辑器，可视化设计。
  • VS Code：微软出品，免费开源，功能强大。下载地址：点击下载

浏览工具

  • Internet Explorer (IE)：Windows 绑定。
  • Opera、Firefox、腾讯 TT、Chrome（推荐）等。
  • QQ 截图快捷键 Ctrl+Alt+A 可测量像素和取色。

1.3 第一个 HTML 页面

<!-- 程序 1-1 -->
<html>
<head>
  <title>我们的班级主页</title>
</head>
<body>
  <h2 align="center">欢迎来到我们的班级网站</h2>
  <br>
  <p>这是我们开发的第一个网页</p>
</body>
</html>

保存为 .html 或 .htm 格式，用浏览器打开即可查看效果。

1.4 网页制作相关技术

CSS

  • 层叠样式表 (Cascading Style Sheet)。
  • 精确控制布局、字体、颜色、背景等。

JavaScript

  • Netscape 开发的脚本语言。
  • 实现交互式 Web 网页，如在线填表、联机发布等。

HTML 是基础架构，CSS 美化页面，JavaScript 实现动态与交互。

第2章 HTML 基础介绍

2.1 HTML 文档结构

  • 完整 HTML 文件包含头部 (head) 和主体 (body) 两部分。
  • 头部可定义标题、样式等；主体是要显示的信息。
<!-- 程序 2-1 -->
<html>
<head>
  <title>一个简单的 HTML 示例</title>
</head>
<body>
  <h1>欢迎光临我的主页</h1>
</body>
</html>

2.1.2 头部内容

  • <head> 头部标记，内容不显示在正文中。
  • 允许的标记：base, link, meta, title, style, script。
  • <title> 指定网页标题，显示在浏览器标题栏。
<html>
<head>
  <title>我的第一个网站</title>
</head>
<body>
</body>
</html>

<meta> 标签

  • 辅助性标签，向浏览器和搜索引擎提供网页信息。
  • 两个主要属性：http-equiv 和 name。

name 属性

  • description：网页描述
  • keywords：关键词
  • author：作者
  • viewport：视口设置
  • robots：爬虫行为

http-equiv 属性

  • expires：网页到期时间
  • pragma：缓存控制
  • refresh：自动刷新
  • set-cookie：cookie 设定
  • content-Type：内容类型

viewport 常见取值

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width：视口宽度等于设备宽度
  • initial-scale=1.0：初始缩放比例 1.0
  • minimum-scale=0.5：允许最小缩放 0.5
  • maximum-scale=2.0：允许最大缩放 2.0
  • user-scalable=no：禁止用户缩放

2.1.3 主体内容

  • <body> 与 </body> 之间放置页面所有内容。
  • 图片、文字、表格、表单、超链接等元素。
<!-- 程序 2-4 -->
<html>
<head>
  <title>我的第一个页面</title>
</head>
<body>
  <h1>这里是文章的标题。</h1>
  <p>这里是文章的段落。</p>
</body>
</html>

2.1.4 编写网页的开头 · DOCTYPE

  • DOCTYPE 是文档类型声明，告诉浏览器用哪个 HTML 版本解析。
  • 必须位于 HTML 文档第一行。
  • 不写 DOCTYPE 浏览器默认怪异模式；写了则启用标准模式。
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title></title>
</head>
<body>
</body>
</html>

2.2 HTML 基本语法

单标记

仅单独使用即可表达完整意思。

<标记名称>
例如：<br> 表示换行

双标记

由首标记和尾标记构成，成对使用。

<标记名称>内容</标记名称>
例如：<b>粗体</b>

标记可以嵌套，但不能交叉嵌套。

2.2.2 属性语法

  • 属性写在首标记内，与标记名之间有空格。
  • 属性值可用引号，也可不用。
<标记名称 属性名1="属性值" 属性名2="属性值">
例如：<hr size="5px" align="center">

2.3 注释

  • 用于在源码中插入注释，浏览器会忽略。
  • 提高代码可读性，便于维护。
<!-- 注释内容 -->

2.4 编写 HTML 文件的注意事项

  • < 和 > 是标记的开始和结束，元素必须关闭。
  • 标记可嵌套，但不能交叉；回车和空格在代码中不起作用。
  • 属性值建议用引号括起；标签名和属性建议小写。
  • 使用缩进风格，便于阅读和维护。
  • 文件扩展名 .htm 或 .html，建议统一用 .html。
  • 文件名由英文字母、数字、下划线组成，避免特殊符号。
  • 网站首页一般为 index.html 或 default.html。

2.5 编写 HTML 文件示例

<!-- 程序 2-5 -->
<html>
<head>
  <title>页面的标题</title>
</head>
<body>
  <p>这是我的第一个页面。 <b>这是粗体文本。</b></p>
  <img src=".img/welcome.jpg">
</body>
</html>

养成良好的编码习惯，注意结构和缩进。

第2章 总结

  • HTML 文件基本结构：<html>、<head>、<body>。
  • <body></body> 是核心部分，浏览器中看到的信息都定义在此。
  • 标记分单标记和双标记，属性写在首标记内。
  • DOCTYPE 声明文档类型，避免怪异模式。
  • 注意文件命名和编码规范。

第3章 文字与段落

3.1.1 添加文字

  • 文字是网页的基础，添加在 <body> 与 </body> 之间。
  • 包括普通文字、空格符、特殊符号以及注释语句。
<!-- 程序 3-1 -->
<html>
<head>
  <title>在网页中添加文字</title>
</head>
<body>
  这是一本介绍 HTML、CSS、JAVASCRIPT 的专业书籍。
</body>
</html>

3.1.2 标题字

  • HTML 定义六级标题，从 <h1> 到 <h6>，字号依次递减。
  • 可设置对齐方式：left、center、right。
<h1 align="center">一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4 align=left>四级标题</h4>
<h5 align=center>五级标题</h5>
<h6 align=right>六级标题</h6>

3.1.3 添加空格 & 3.1.4 特殊符号

空格

  • HTML 自动删除多余空格，只保留一个。
  • 用 &nbsp; 表示空格。
这是一本 &nbsp;&nbsp; 介绍 HTML 的专业书籍。

特殊符号

  • &amp; → &
  • &copy; → ©
  • &lt; → <
  • &gt; → >
版权所有 &copy;

3.1.5 注释语句

  • 增加代码可读性，浏览器中不可见。
  • 基本语法：<!-- 注释内容 -->
<!-- 程序 3-5 -->
<html>
<head>
  <title>在网页中添加注释</title>
</head>
<body>
  <center>
    <pre><!--pre 代表原样显示排版格式 -->
我们永远的家
—— 多媒体专业!
    </pre>
  </center>
</body>
</html>

3.2 文字样式

  • 使用 <font> 设置字体、字号、颜色。
  • 基本语法：<font face=" " size=" " color=" ">...</font>
<!-- 程序 3-6 -->
<center>
  <font face="黑体" size=6 color="red">
    我们是一个团体, 不会丢下谁, 不会落下谁。共同奋进!
  </font>
</center>

3.3.1 粗体、斜体、下划线

<b>粗体</b>
<i>斜体</i>
<u>下划线</u>
<center>
  <font color="#FF0000" size=3>
    <b>这些文字是粗体的</b>
  </font><br>
  <i>这些文字是斜体的</i><br>
  <u>这些文字带有下划线</u>
</center>

删除线

3.4.1 段落标记

  • 用 <p> 标记开始一个段落，不同段落间有间距。
  • 基本语法：<p>...</p>
<p>五十个不同的分子, 在不同状态下进入了同一容器...</p>
<p>在不地碰撞和摩擦中, 分子也不断地变化...</p>

换行

居中

<center>内容居中</center>
<center>《关于我们》</center>
<center>五十个不同的分子...</center>
