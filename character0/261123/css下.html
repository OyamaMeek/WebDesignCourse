📦 盒子模型介绍

在 CSS 中，每一个元素都被看作一个矩形盒子。盒子模型由 content（内容）、padding（内边距）、border（边框）、margin（外边距） 四部分组成。

margin（外边距）
border（边框）
padding（内边距）
content（内容）
元素内容区域 文字 / 图片等
width（宽度）

四层结构说明

  • content：核心内容区域
  • padding：内容与边框之间的填充
  • border：盒子的边框
  • margin：盒子与其他元素的距离

生活类比

手机包装盒：外包装厚度 = border，内部泡沫 = padding，手机 = content，盒子间距 = margin。

盒子模型种类

CSS 中存在两种盒子模型：标准盒子模型（W3C） 与 怪异盒子模型（IE 传统），它们的核心区别在于 width 的计算范围。

标准盒子模型（content-box）

width 仅指 content 的宽度。

margin
border
padding
content width = 内容宽度 
总宽 = width + padding + border + margin

怪异盒子模型（border-box）

width 包含 content + padding + border。

margin
border
padding
content width = 内容 + padding + border 
总宽 = width + margin

可通过 box-sizing: border-box; 将元素切换为怪异盒模型计算方式。

box-sizing 属性

box-sizing 是 CSS3 属性，用于指定盒子模型的计算方式。

box-sizing: content-box | border-box | inherit;

content-box（默认）

标准盒子模型。宽度/高度仅设置内容区域。

width: 200px;
box-sizing: content-box;
实际总宽 = 200px + padding + border

border-box

怪异盒子模型（IE 传统）。宽度/高度包含内容、内边距和边框。

width: 200px;
box-sizing: border-box;
实际总宽 = 200px（含 padding 和 border）

设置边界 margin

margin 控制元素与页面其他内容之间的空白距离，包括上、右、下、左四个方向。

margin-top: 长度 | 百分比 | auto;
margin-right: 长度 | 百分比 | auto;
margin-bottom: 长度 | 百分比 | auto;
margin-left: 长度 | 百分比 | auto;
/* 复合写法：margin: 上 右 下 左; */

示例

div {
  margin-top: 20px;
  margin-right: auto;
  margin-bottom: 20px;
  margin-left: auto;  /* 水平居中 */
}

设置元素边框 border

边框由三个属性共同决定：border-style、border-width、border-color。

border-style 边框样式

border-style: solid | dashed | dotted | double | ...;

复合属性可设置1~4个值，顺序为上、右、下、左。

border-width 边框宽度

border-width: thin | medium | thick | 长度;

border-color 边框颜色

border-color: 颜色关键字 | RGB值;

border 综合设置

border: 宽度 样式 颜色;

例如：border: 2px solid #6366f1;

border-style 边框样式详解

border-style 是复合属性，可以设置1~4个值，分别对应四条边。

取值规则

  • 一个值：四条边框均使用该值
  • 两个值：上下使用第一个值，左右使用第二个值
  • 三个值：上使用第一个，左右使用第二个，下使用第三个
  • 四个值：顺序为上、右、下、左
/* 四条边框均为实线 */
border-style: solid;

/* 上下实线，左右虚线 */
border-style: solid dashed;

/* 上实线，左右虚线，下双线 */
border-style: solid dashed double;

/* 上、右、下、左分别设置 */
border-style: solid dashed dotted double;

设置元素内边界 padding

padding 控制边框与内部元素之间的空白距离，同样包括四个方向。

padding-top: 长度 | 百分比;
padding-right: 长度 | 百分比;
padding-bottom: 长度 | 百分比;
padding-left: 长度 | 百分比;
/* 复合写法：padding: 上 右 下 左; */

说明

  • 百分比是相对于父元素宽度计算
  • 不允许使用负值
  • 复合属性的取值规则与 border-style 相同

背景与颜色的使用

设置颜色方法

  • RGB 数值：rgb(255, 0, 0)
  • RGB 函数：rgb(100%, 0%, 0%)
  • 颜色名称：red、blue 等
  • 十六进制：#ff0000
color: #6366f1;
background-color: rgb(241, 245, 249);

背景颜色属性

background-color: 颜色值;

用于设置元素的背景颜色。

背景图片属性

background-image: url("image.jpg");
background-repeat: repeat | no-repeat | repeat-x | repeat-y;
background-position: 位置;

CSS 区域标签

常用的区域标签用于组织页面结构，配合 CSS 实现布局。

<div>

块级元素，常用于划分页面区域、包裹内容。

<span>

行内元素，用于对文本片段设置样式。

语义标签

<header>、<nav>、<main>、<footer> 等。

<div class="container">
  <header>页头</header>
  <main>主要内容</main>
  <footer>页脚</footer>
</div>

CSS 布局 - 标准流、浮动和定位

标准流（文档流）

元素按照 HTML 中的顺序自上而下、从左到右排列，是默认的布局方式。

  • 块级元素独占一行
  • 行内元素水平排列

浮动（float）

使元素脱离标准流，向左或向右浮动，常用于多栏布局。

float: left | right | none;

定位（position）

通过 position 精确控制元素位置。

  • static：默认值
  • relative：相对定位
  • absolute：绝对定位
  • fixed：固定定位

🧪 综合布局案例：简易后台管理页

综合运用 盒子模型、浮动/弹性 与 定位/标准流，实现一个简单的后台管理页面结构。

HTML 结构

<div class="layout">
  <header class="header">后台管理系统</header>
  <div class="body">
    <aside class="sidebar">
      <p>菜单</p>
      <ul>
        <li>首页</li>
        <li>用户管理</li>
        <li>设置</li>
      </ul>
    </aside>
    <main class="main">
      <h4>欢迎页</h4>
      <p>这里是内容区域……</p>
    </main>
  </div>
  <footer class="footer">© 2025 后台系统</footer>
</div>

关键 CSS

.layout {
  display: flex;
  flex-direction: column;
  height: 100%;
}
.body {
  display: flex;
  flex: 1;
}
.sidebar {
  width: 26%;
  background: #f1f5f9;
  border-right: 1px solid #e2e8f0;
}
.main {
  flex: 1;
  padding: 12px;
}
.header, .footer {
  background: #1e293b;
  color: #fff;
  padding: 10px 16px;
}
